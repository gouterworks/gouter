# 無料でサイトの数字を読む（2026-10-05）

**Windsor.ai の無料枠が終わったので切った。** 代わりに、Googleの中だけで完結させる。
**費用はゼロ。** GA4もサーチコンソールも、APIまで無料。有料だったのは中継していた
Windsor.ai だけだった。

## 何をするか

Googleの無料のしくみ（Apps Script）で、**GA4とサーチコンソールの数字を
スプレッドシートに自動で書き出す。** 書き出し先はさとこさんのDriveなので、
**Claudeはそこから読める。**

```
GA4 ────┐
        ├─→ Apps Script（無料・毎週自動）─→ スプレッドシート ─→ Claudeが読む
サーチコンソール ┘
```

**毎回手で書き出す必要がなくなる。** 一度置けば毎週月曜の朝に勝手に更新される。

**サーチコンソールが読めるようになるのが一番大きい。** Windsor.ai では
gouter.works がつながっていなかったので、順位とクエリは最後まで見えなかった。
これが見えると「あと少しで1ページ目」の記事を数字で選べる。

## 置き方

ファイルは `tools/analytics/` にある。

### 1. スプレッドシートを作る

Driveで新しいスプレッドシートを作る。名前は `gouter.works 数字` など何でもいい。

### 2. スクリプトを貼る

そのスプレッドシートで **拡張機能 → Apps Script**。

- 開いたエディタの `コード.gs` の中身を全部消して、`tools/analytics/Code.gs` を貼る
- 左の歯車（プロジェクトの設定）で**「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック**
- 現れた `appsscript.json` の中身を全部消して、`tools/analytics/appsscript.json` を貼る
- 保存

### 3. どのサイト・どのプロパティか確定させる

関数を `setUp` にして**実行**。初回は認可を聞かれるので許可する
（「このアプリは確認されていません」と出たら「詳細」→「安全ではないページに移動」。
自分で書いたスクリプトなので問題ない）。

**「設定メモ」シート**に、見られるサイトとGA4プロパティの一覧が出る。
そこから値をコピーして、`Code.gs` の頭の2行を書き換えて保存する。

```javascript
var SITE_URL     = 'sc-domain:gouter.works';  // 設定メモの「サーチコンソール」の行
var GA4_PROPERTY = '123456789';               // 設定メモの「GA4」の行
```

**`GA4_PROPERTY` はプロパティID。アカウントID（`271991344`）ではない。**
ここを間違えると GA4 のシートが「取得失敗」になる。

### 4. 動かす

関数を `run` にして**実行**。シートが増える。

| シート | 中身 |
|---|---|
| `SC_クエリ` | どの検索語で、何回表示されて、何回クリックされ、平均何位か |
| `SC_ページ` | 記事ごとの表示・クリック・順位 |
| `SC_ページ別クエリ` | **どの記事がどの語で拾われているか。いちばん効く** |
| `SC_日別` | 日ごとの推移 |
| `GA4_ページ` | ページ別のPVとセッション |
| `GA4_着地` | 最初に開かれたページ |
| `GA4_流入元` | どこから来たか |
| `GA4_日別` | 日ごとのPV |

### 5. 毎週ひとりで動くようにする

関数を `毎週動かす` にして**実行**。これで毎週月曜の朝7時に更新される。
以降は何もしなくていい。

### 6. Claudeに知らせる

スプレッドシートの名前かURLを伝える。以降は「数字見て」で読める。

## 決めごと

- **期間は直近4か月**（`MONTHS_BACK`）。もっと欲しければこの数字を変える。
  サーチコンソールは16か月まで遡れる
- **終わりは3日前まで。** GA4は直近の数字が揃わないので、揃ってから取る
- **シートは毎回まるごと置き換わる。** 手で書き込むと消える。メモは別シートに書く
- サーチコンソールのプロパティが**ドメイン単位なら `sc-domain:gouter.works`**、
  URL単位なら `https://gouter.works/` になる。`setUp` が正しい形を教えてくれる

## つまずくところ

| 症状 | 原因 |
|---|---|
| `SC_*` が全部「取得失敗 HTTP 403」 | サーチコンソールに gouter.works が登録されていない。**まず登録が必要** |
| `GA4_*` が「取得失敗」 | `GA4_PROPERTY` にアカウントIDを入れている。プロパティIDに直す |
| `AnalyticsData is not defined` | `appsscript.json` を貼り替えていない。手順2をやり直す |
| シートが空 | 期間内にデータが無い。`MONTHS_BACK` を増やす |

## これまでの数字
