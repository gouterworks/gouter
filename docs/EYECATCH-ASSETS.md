新しい記事のぶんは、**正しいフォントが入っているページを `copy-design` で複製**して作る。
まっさらなページを足すとフォントが変わり、後から直せない。

母艦は過去のコラムのアイキャッチが全部入っている。**母艦は編集しない。** ページを複製して作業用に回す。

### 必ず母艦のページを複製してから作る

母艦の標準フォントは **`YADK30shh-I`（weight: normal）**。

Canvaのコネクタには**フォント種別を変える操作が無い**（`format_text` はサイズ・色・太字までで、
フォント自体は変えられない）。まっさらなページにテキストを足すと別のフォントになり、
**後から直せない**。実際に9327用のページで `YACgEZ1cb1Q` / bold になっていて、作り直しになった。

サイズは16:9（1280×720）。文字組みは**3行構成**。

```
上段（小）  … 記事の要点を短く（例：投稿画像に自動でウォーターマーク）
中央（大）  … 主題（例：Easy Watermark）
下段（小）  … カテゴリや対象（例：WordPressプラグイン）
```

背景写真の上に白抜き文字。読めるように暗いオーバーレイを敷く。

**オーバーレイの濃さは背景で変える。** 既定は不透明度0.4。ただし白い被写体が広く写る写真
（付箋のボードなど）では白文字が沈むので、**0.6まで濃くする**。9363で実際に0.4では読みにくかった。

**下段は9文字まで。** 枠の幅が847pxで文字が90pxなので、10文字を超えると折り返して
2行目が枠の外に出る。上段は1172pxあるので11文字程度まで入る。

## 本数の見通し

母艦由来の18枚が使えない前提だと、**供給は外部素材の取り込みが主線**になる。
Pexelsなどの無料ライセンス素材を `upload-asset-from-url` でCanvaへ入れる経路は確立済み
（実績：Pexels 3874627）。1本ごとに新しく取り込めばよいので、枚数の上限は無い。

量を優先する場合の代替：

- 背景写真を5〜10枚のセットで用意してローテーション
- ブランド色（ネイビー＋イエロー）のベタ背景でシリーズ感を出す

記事ごとに毎回選ぶやり方は、いちばんきれいだが量産のボトルネックになる。

## 決まりごと

- alt属性は日本語で必須
- 横幅1200px以上で書き出す
- **母艦は無編集**。読み取り後にトランザクションを破棄する
- タイトルとアイキャッチの文言は対にする。片方を直したらもう片方も直す
- **過去記事で使った写真を新規記事に使わない**
