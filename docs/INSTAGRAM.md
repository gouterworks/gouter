# インスタグラム運用

[@gouter.works](https://www.instagram.com/gouter.works/) の運用ルール。**記事の運用（`DAILY-RUN.md`）とは目的も指標も別**にする。

## 決めたこと

| | |
|---|---|
| 目的 | **営業資材**。SNS運用代行を売っている以上、止まったアカウントは商品の反証になる |
| 指標 | **保存数とプロフィールアクセス**。サイト流入では測らない |
| 本数 | **週2本**。毎日にしない |
| 形式 | **カルーセル7〜9枚**。アイキャッチ1枚の転載はしない |
| 何を出すか | 「配布物が付く回」と「現場で見たこと」だけ。**一般論の解説回は出さない** |
| 自動化 | **最初の8本は手で出す。** そのあと数字を見て決める |

## なぜ「記事をそのまま流す」をやらないのか

2026-09-09にGA4を見て決めた。gouter.works の直近3か月（2026-06-09〜09-08）、全794セッション。

| 経路 | セッション |
|---|---|
| Direct | 404 |
| 検索（google 183 / bing 126 / yahoo 34 他） | 345 |
| SNS全部（facebook 14 / linkedin 4 / t.co 3） | 21 |
| **Instagram** | **0** |

ランディングページ側はこう。

| ページ | セッション | 性格 |
|---|---|---|
| `/` | 192 | |
| `/4212` | 168 | 配布物 |
| `/7864` | 80 | 使っている道具の話 |
| `/567` | 34 | 現場の型 |
| 9327番以降（AIで書いた60本超） | **合計18** | 一般論の解説 |

読み取れることは3つ。

1. **インスタからの流入は0。** SNS全部でも21/794。いまインスタを再開してもPVは動かない。
   **PVを目的に置くと、3か月後に「効かなかった」と誤った結論を出す。** だから指標を分ける
2. **一般論の解説記事はサイトで効いていない。** 効かない材料を別チャネルに横流ししても効かない。
   ただし9327以降は公開が8月末からで日が浅い。`THEME-BACKLOG.md` の
   「3か月経った6月のぶんも最高16セッション」と合わせて、傾向として読む
3. それでも止めたままにはできない。**SNS運用代行を商品にしているのに、自社のインスタが止まっている。**
   これはPVより先に手を打つ理由になる

## 何を出すか

`THEME-BACKLOG.md` の4軸のうち、**「現場で見たこと」と「配布物が付く回」だけ**を出す。

- LINE・UTAGEの実務は、画面の話になるので図が要る。当面は出さない
- 読書・朝の時間は、Goûterの商品と遠い。出さない
- **一般論のマーケティング解説は出さない。** サイトで効いていないものを、そのまま持ち込まない

**記事1本につきカルーセル1本ではない。** 週2本のほうが少ないので、記事の側から選ぶ。
選べる回が無い週は**出さない**。無理に埋めない。

## 割り方

執筆マニュアルの決めごとが、そのままカルーセルの構造になる。

| 枚 | 中身 | 出どころ |
|---|---|---|
| 1 | 表紙 | **タイトルの前半16字**。`！` `？` で切ってあるので、そのまま表紙のコピーになる |
| 2 | 結論 | PREP法の P。リード直後にある |
| 3〜6 | 本文 | **H2ごとに1枚。** H2は3,000字で4本までと決めてあるので、素直に割れる |
| 7 | 一次情報 | フロントマターの `primary` に書いたもの。**現場で見たこと、具体の数字、失敗** |
| 8 | 導線 | プロフィールへ |

7枚目が要。**ここがGoûterと他の投稿の差になる。** `primary` が薄い記事は、カルーセルにしない。

記事のルールはそのまま持ち込む。**実績を捏造しない。** 「クライアントで◯%改善」は実際の数字があるときだけ。

## キャプション

- **インスタの中で完結させる。** 「続きはブログで」を主目的にしない。リンクは踏まれない前提で設計する
- 記事の要約ではなく、**カルーセルで言い足りなかった1つ**を書く
- 最大2,200字。使い切らない
- ハッシュタグは**5〜10**。30個並べない。テーマ＋地域（宗像・福岡）

## 出す時間

**火曜と金曜の20:00（日本時間）を出発点にする。** 相手は店主・個人事業主で、店が落ち着く時間。
根拠のある数字ではないので、**8本ぶんの数字を見て直す。**

記事の枠（朝7:00）とは重ねない。同じ時間に同じ内容が2か所から出ても意味がない。

## 作り方

1. その週に出す記事を1〜2本選ぶ（上の「何を出すか」の基準で）
2. 8枚ぶんの文言を割る（上の表）
3. Canvaで画像を作る。**母艦（`DAF2Hmjvfm4`）は編集しない。** 作業用デザインを `copy-design` で複製する。
   詳細は `EYECATCH-ASSETS.md`。アイキャッチと同じ落とし穴（まっさらなページはフォントが変わる）がある
4. **サイズは 1080×1350（4:5）、書き出しはJPEG。** アイキャッチのPNGとは別なので注意
5. 背景写真は**過去記事のアイキャッチと重複させない**。使ったものは `EYECATCH-ASSETS.md` に追記する
6. 投稿する。**最初の8本は手で出す**

## 自動化 — 8本出してから決める

技術的には最後までつながることを確認済み（2026-09-09）。

- Windsor の Instagram コネクタに `create_carousel_post` がある。
  **2〜10枚、JPEG、8MB以下、アスペクト比4:5〜1.91:1、公開URL、キャプション2,200字まで**
- 画像の公開URLは、WordPressのメディアがそのまま使える（`wp.py featured` が既に画像を上げている）
- つまり **Canva → 書き出し → WPメディア → カルーセル投稿** で全部自動化できる

**ただし、いまWindsorにつながっているのは Google Ads / GA4 / Search Console だけ。
Instagram は未接続。** 自動化するなら、まずビジネスアカウントを接続する。

自動化から入らない理由は、記事の運用で一度やったことと同じ。
**効かないものを自動で量産することになる。** 8本＝4週間ぶんの保存数を見てから決める。

`HANDOFF.md` の6番にある Blog2Social はここでは使わない。**あれはアイキャッチ1枚の自動転載で、
カルーセルを作れない。** 手数はゼロになるが、いちばん伸びない形になる。
