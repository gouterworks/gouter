サイトの文章を書いていて、手が止まる場所があります。**「弊社」と書くか、「私たち」と書くか。**

どちらでも意味は通ります。だから、なんとなくで決めて、**ページによってバラバラになります。**トップは「弊社」、ブログは「私」、問い合わせ後のメールは「当社」。

読む側から見ると、**同じ人が書いているように見えません。**

## 文章の一人称の使い分けは、距離の設定

一人称は、**自分と読む人の距離を決めるもの**です。丁寧さの度合いではありません。

| 一人称 | 合う場面 | 合わない場面 |
|---|---|---|
| 弊社 | 取引先への文書、見積、契約まわり | **1対1で話しかける文章**（硬く、遠く感じる） |
| 当社 | 会社としての告知、お知らせ、規約 | 個人の考えを書くとき |
| 私たち | サイトの紹介文、採用ページ | **1人でやっている事業**（実態と合わない） |
| 私 | ブログ、事例の解説、経験談 | 会社としての正式な連絡 |

**「弊社」はへりくだる言い方**なので、取引先に向けた文書では自然です。ただし、これをブログに使うと、**読む人が「取引先の1社」として扱われている感じ**になります。まだ買っていない人にとっては、距離が遠い。

**「当社」は中立**です。へりくだりも親しみもない。お知らせや規約のような、感情を乗せない文章に向きます。裏を返すと、**親しみを出したい場面では冷たく読まれます。**

**「私たち」は、複数いることが前提**です。1人でやっている事業で使うと、あとで会ったときに「1人だったんですね」となります。**嘘ではなくても、期待とずれます。**

**「私」がいちばん近い**一人称です。経験や失敗を書くときは、これでないと成立しません。「弊社は失敗しました」とは書けない。書けたとしても、**誰が失敗したのかがぼやけます。**

一人称を近くすることには、実際の効果があります。**書ける内容が変わる**ことです。「私」で書き始めると、自分が見たことしか書けなくなる。**一般論に逃げられなくなります。**逆に「弊社」で書き始めると、どこかで読んだ話をまとめただけの文章になりやすい。

小さな事業では、これが強みになります。大きな会社は、担当者個人の経験を出しにくい。**個人の名前で書けることが、そのまま差になります。**

## 選ぶ基準は2つだけ

迷ったときは、この2つで決まります。

**1つめ。読む人は何人か。**

大勢に向けたお知らせなのか、**目の前の1人に話しかけている**のか。

サイトのトップページやブログは、実際には大勢が読みますが、**読んでいる瞬間は1人**です。だから、1人に話しかける前提で書きます。ここで「弊社では」と始めると、掲示板の文章になります。

規約や料金改定のお知らせは、逆です。**全員に同じ内容を伝える**ものなので、「当社」で構いません。

判断に迷ったら、**声に出して読んでみる**のが早い。「弊社では、こういう場面をよく見ます」と口に出すと、話し言葉として不自然だと分かります。**サイトの文章は、黙って読まれていても、頭の中では声になっています。**

**2つめ。書いているのは、会社としてか、人としてか。**

「こういう考えでやっています」「こんな失敗をしました」は、**人として**書いています。ここは「私」。

「営業時間を変更します」「価格を改定します」は、**会社として**の連絡です。ここは「当社」か「弊社」。

この2つで分けると、1つのサイトの中で一人称が変わることになります。**それは問題ありません。**トップページは「私たち」、ブログは「私」、規約は「当社」。**種類ごとに揃っていれば、読む人は違和感を持ちません。**

1人でやっている事業で「私たち」を使いたくなる場面もあります。**大きく見せたい**からです。ただし、これは問い合わせのあとで必ずばれます。**期待して連絡してきた人が、想像より小さいと分かる**のは、最初から1人だと知っているより印象が悪い。

規模を隠さないほうが、結果として合う相手が来ます。**1人だからこそ頼みたい**という人は、実際にいます。

まずいのは、**同じ種類の中で揺れる**ことです。ブログの記事Aは「私」、記事Bは「弊社」。ここが揃っていないと、書き手が定まっていないように見えます。

誰がやっている事業かをどう見せるかは[運営者情報ページの書き方](https://gouter.works/?p=9190)にも書きました。**一人称は、そのページの延長にあります。**

## 決めたら、一覧にして残す

決めた内容は、**短い一覧にして手元に置きます。**

- サイトのトップ・サービス紹介 → **私たち**（1人の事業なら「私」）
- ブログ・事例 → **私**
- お知らせ・規約・料金改定 → **当社**
- 見積・請求・契約書 → **弊社**

これだけです。書くときに迷ったら、この4行を見る。**迷う時間がなくなるだけでも効果があります。**

この一覧は、**人に書いてもらうときにも使えます。**外注のライターに渡す一枚があるかないかで、直しの量が変わります。一人称が違う原稿は、全部読み直して直すことになるので、**先に渡すのがいちばん安い**方法です。

一人称と一緒に決めておくと楽なものが、あと2つあります。

**読む人の呼び方。**「お客様」「みなさま」「あなた」。一人称が「私」で相手が「みなさま」だと、距離がちぐはぐになります。**1対1で書くなら、相手も1人**として呼びます。

**文末。**「です・ます」で統一するか、途中で「〜だ」を混ぜるか。一人称を近くしたのに文末が硬いままだと、読んだときに落ち着きません。基本は「です・ます」で、**言い切りたい1文だけ短くする**くらいがちょうどいい。全部を言い切りにすると、指示されているように読まれます。

過去の記事を全部直す必要はありません。**これから書くものから揃えます。**よく読まれているページだけ、見直したときに直せば足ります。どのページが読まれているかは[サーチコンソールの検索クエリ](https://gouter.works/?p=9377)で分かります。

## まとめ

一人称は丁寧さの問題ではなく、**距離の設定**です。

- **弊社**はへりくだる言い方。取引先への文書向き。ブログに使うと遠い
- **当社**は中立。お知らせ・規約向き
- **私たち**は複数いることが前提。1人の事業では使わない
- **私**がいちばん近い。経験や失敗を書くときはこれ
- 選ぶ基準は**読む人が何人か**と**会社としてか人としてか**の2つ
- 種類ごとに揃っていれば、**サイトの中で変わっていい**
- 決めたら**4行の一覧**にして手元に置く

いま、自分のサイトのトップとブログを並べて見てください。**一人称が違っているなら、どちらかが実態と合っていません。**
