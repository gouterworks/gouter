資料が見つからない。共有フォルダを開くと、**「新しいフォルダ」「資料」「その他」**が並んでいます。

整理しようと思って、まずフォルダを作り直します。部署別、年度別、案件別。**きれいに分かれた構成ができて、3か月後にはまた元通り。**

フォルダから手をつけると、たいていこうなります。**分類は、人によって違うからです。**

## 社内資料の整理方法は、フォルダより名前が先

同じ請求書を、ある人は「経理」に入れ、別の人は「A社」に入れます。**どちらも間違っていません。**分類の基準が2つあるだけです。

人が増えるほど基準が増え、**入れる場所が分かれます。**分かれたものは、探すときに見つかりません。

探し方には2つあります。

| 探し方 | 成り立つ条件 | 破綻する場面 |
|---|---|---|
| 階層をたどる | 分類の基準が全員で同じ | **人が3人を超えると崩れる** |
| 名前で検索する | ファイル名に必要な言葉が入っている | 名前が「資料.xlsx」だと出ない |

**小さな組織で現実的なのは、下の検索のほうです。**階層をたどるやり方は、全員が同じ基準を持ち続けないと成立しません。人の出入りがあるだけで崩れます。

検索なら、**入っている場所がどこでも見つかります。**必要なのはファイル名だけ。だから、フォルダより名前を先に決めます。

ここで1つ、誤解されやすいところがあります。**フォルダを作るなという話ではありません。**フォルダは要ります。ただし、**フォルダは「探すため」ではなく「置くため」**のものと考える。探すのは検索、置き場所はフォルダ。役割を分けると、両方が軽くなります。

探す時間は、思っているより積み上がります。1回3分の探しものが1日5回あれば、15分。**月にすると5時間**です。この計算は、自分の数字で一度やってみてください。時間が見えると、名前を決める手間のほうが軽く見えます。

## ファイル名の型を1つ決める

型は1つで足ります。

```
日付_相手または案件_種類_版
```

たとえばこうなります。

- `20260827_A商店_見積_02.xlsx`
- `20260815_夏キャンペーン_チラシ入稿_01.ai`
- `20260801_定例_議事録.docx`

日付を先頭に置くのは、**並べ替えるだけで時系列になる**からです。`2026-08-27` でも構いませんが、区切りを入れないほうが短くて済みます。

**種類の言葉は、10個くらいに決めておきます。**見積、請求、契約、議事録、企画、入稿、報告。ここが人によって「見積書」「お見積り」と揺れると、検索で拾えなくなります。**決めた言葉の一覧を、共有フォルダのいちばん上に置いておく**のが確実です。

版の番号は、**直したら必ず増やします。**`_最終`、`_最終2`、`_本当に最終` という並びは、どれが最新か分かりません。数字なら、大きいほうが新しいと決まっています。

使わないほうがいい文字もあります。**スペースと丸括弧は避ける**のが無難です。システムによっては扱いが変わり、リンクが切れることがあります。区切りはアンダースコアに統一します。

型を守ってもらうコツは、**見本を1つ置いておく**ことです。ルールを文章で説明されるより、正しい名前のファイルが1つ並んでいるほうが早く伝わります。

型を決めたら、**過去のファイルは触りません。**全部やり直そうとすると終わらないので、**これから作るものから**にします。よく使う古いファイルだけ、開いたついでに直す。半年もすれば、よく使うものはひととおり新しい名前になっています。

## フォルダは浅く、置き場所は決めておく

名前を決めたうえで、フォルダは**浅く作ります。**目安は3階層まで。

```
2026年度 / A商店 / （ファイル）
```

深くすると、たどり着くまでのクリックが増え、**入れるのが面倒になって、デスクトップに置かれます。**デスクトップに置かれたファイルは、その人しか見られません。

1階層目は、年度でも案件でも構いません。**迷ったら、自分がいちばんよく口に出す言葉**にします。会話で「A商店の件」と言っているなら、案件が先。「今年度の」と言っているなら、年度が先です。

もう1つ決めるのが、**まだ分類できないものの置き場所**です。「一時」フォルダを1つ作り、そこに入れていい。**置き場所に迷ったせいでデスクトップに残るほうが問題です。**

ただし、一時フォルダは**月に1回空にします。**空にする日を決めていないと、そこが第2の共有フォルダになります。空にするときは、名前を型に直してから移すだけです。

古いファイルを消すかどうかも、先に決めておきます。**消さないほうが安全ですが、置いたままだと検索に混ざります。**年度が終わったものは「保管」フォルダにまとめて移す。**消すのではなく、探す範囲から外す**という扱いにすると、判断が軽くなります。

契約書のように保存期間が決まっているものは、**その年数を名前の横にメモしておく**と、あとで迷いません。期間の決まりは書類の種類で違うので、自分の事業に何が当てはまるかは確認してください。

やめたほうがいいのは、**個人ごとのフォルダを共有の中に作る**ことです。「田中さん用」「山田さん用」。作った本人以外は開かなくなり、**中に入った資料は共有されていないのと同じ**になります。

こうしたルールは、**人が増えたときに効いてきます。**新しく入った人は、フォルダの構成ではなく名前の型を覚えれば済む。**引き継ぎの説明が1枚で終わります。**

ルールを決めても現場で使われないことがあります。原因はたいてい同じで、**古いやり方を止めていないから**です。この話は[ツールを導入しても現場が使わない](https://gouter.works/?p=9397)にも書きました。共有フォルダを作ったのにメール添付が続いているなら、それと同じ状態です。

社内の資料が整うと、**外に出す資料も速く作れます。**過去の見積や提案を探す時間が減るからです。何を載せるかで迷う場面は[運営者情報ページの書き方](https://gouter.works/?p=9190)にも通じます。

## まとめ

社内資料の整理は、フォルダの構成ではなく**名前の型**で決まります。

- 分類は人によって基準が違う。**3人を超えると階層は崩れる**
- 現実的なのは**検索で見つける**やり方。必要なのはファイル名だけ
- 型は`日付_相手または案件_種類_版`の1つ。**種類の言葉は10個ほどに固定する**
- 版は**数字で増やす。**「最終」は使わない
- フォルダは**3階層まで。**深いと入れるのが面倒になり、デスクトップに残る
- **一時フォルダを1つ作り、月に1回空にする**
- 過去のファイルは触らない。**これから作るものから**

まず、種類の言葉を10個書き出してください。**そこが揃っていないと、型を決めても検索で拾えません。**
