見積書を出した翌日に、電話が鳴る。**「もう少し安くなりませんか」**

この一言に、毎回同じだけ疲れます。断れば関係が悪くなる気がして、受ければ後から苦しくなる。

ただ、値引きを求められる見積書には、共通した形があります。**金額の問題ではなく、書き方の問題であることが多い。**

## 見積書で値引きを言われるのは「一式」が原因

いちばん多いのが、これです。

```
ホームページ制作一式    500,000円
```

この見積書を受け取った側は、**500,000円という数字しか判断材料がありません。** 高いか安いかを判断する材料が無いので、「高い気がする」で終わります。そして高い気がしたら、言えることは1つしかない。安くしてくれ、です。

一式で書くと、値引きの矛先が総額に向きます。総額に向いた交渉は、こちらが折れるか断るかの二択になります。**間がありません。**

工程で分けると、こう変わります。

| 項目 | 金額 |
|---|---|
| 設計・構成（10ページぶん） | 120,000円 |
| デザイン（トップ＋下層3型） | 180,000円 |
| 実装 | 150,000円 |
| 写真の手配・加工 | 30,000円 |
| 公開後の初期サポート（1か月） | 20,000円 |

同じ50万円でも、受け取る側の反応が変わります。**「写真はこちらで用意します」と言われるようになる。** これは値引きではなく、範囲を減らした結果の減額です。こちらの手間も同じだけ減っています。

一式のままだと、この会話は起きません。**手間はそのままで、金額だけが下がります。**

分ける粒度は、5つから8つくらいが目安です。細かすぎると読まれません。**「これは要る」「これは自分でやれる」を相手が判断できる単位**まで割るのが基準です。

もう1つ、分けることには副次的な効果があります。**こちらが何に時間を使っているかが伝わる**ことです。

一式で50万円と書くと、相手は「50万円の作業」を想像します。想像は、たいてい実際より小さくなります。設計に何日、デザインに何日と分かれていれば、その想像の幅が狭まります。**値引きを言われる前に、納得の材料を渡しておく**という考え方です。

逆に、分けたことで「この項目は要らないのでは」と言われることもあります。それは悪いことではありません。**要らないと言われた項目を外せば、こちらの作業も減ります。** 総額だけを削られるより、はるかに健全な結果です。

## 値引きの代わりに出すものを、先に決めておく

それでも値引きを求められることはあります。**そのときに出す手を、見積を作る段階で決めておきます。**

値引きを断るのが苦しいのは、その場で考えているからです。用意しておけば、断る必要がなくなります。

**1つめ。範囲を減らす**

「この金額でしたら、写真の手配を外す形になります」。金額を下げる代わりに、やることを減らす。**当たり前のようですが、口に出さないと相手には伝わりません。** 相手は「同じ内容で安くなる」と思っています。

**2つめ。支払いを分ける**

総額は変えず、着手時と納品時で分ける。3回に分ける。**資金繰りが理由の値引き要請は、これで解決することがあります。** 「高い」ではなく「今は出せない」だった、という場合です。

**3つめ。期間を延ばす**

急ぎで受けていた案件を、通常の納期に戻す。特急料金ぶんが下がります。

**4つめ。次の条件を付ける**

今回はこの金額で、次回から通常価格に戻す。または、実績として掲載させてもらう。**掲載の許可は、こちらにとって値引き額に見合う価値があることがあります。**

この4つを、見積書と一緒に出す必要はありません。**聞かれたときに、迷わず出せる状態にしておくだけでいい。** 迷って「少し考えます」と言った時点で、値引きできる余地があると受け取られます。

契約の範囲や支払いをどこまで文書にしておくかは、[業務委託契約書の注意点！小さな会社ほど揉めるのは支払いと範囲](https://gouter.works/?p=9378)にまとめました。

## 見積書に必ず書く4つの項目

値引き交渉を減らす見積書には、金額以外の項目が入っています。

**有効期限**

「本見積書の有効期限は発行日より30日といたします」。**これが無いと、半年前の見積で発注が来ます。** 材料費も工数も変わっているのに、断りにくくなる。

**含まないもの**

含むものを書くだけでは足りません。**含まないものを明示します。**

- 写真の撮影費
- 原稿の作成費
- 公開後の更新作業
- ドメイン・サーバーの費用

ここを書いていないと、後から「当然入っていると思った」が起きます。**揉めるのはたいてい、金額ではなく範囲です。**

**修正の回数**

「デザイン修正は2回まで。3回目以降は1回あたり◯◯円」。回数を書くと、相手も回数の中で意見をまとめてくれます。**書かないほうが、お互いに終わりが見えなくなります。**

**前提条件**

「原稿は貴社よりご支給いただく前提です」「ページ数が増える場合は別途お見積りいたします」。**前提が崩れたときに金額が動くことを、先に共有しておきます。**

この4つを入れると、見積書は1枚では収まりません。2枚になってかまいません。**枚数より、後から揉めないことのほうが大事です。**

書き足すのが面倒に感じるなら、**一度作って使い回します。** 有効期限、含まないもの、修正回数、前提条件。この4項目は案件ごとに大きくは変わりません。ひな形に固定の文章として入れておけば、毎回書く手間はありません。

ひな形を作るときは、**過去に揉めた案件を思い出しながら書く**のがいちばん早い。「あのとき言っておけばよかった」と思ったことを、そのまま1行にします。揉めた回数だけ、ひな形は強くなります。

なお、値引きに応じるかどうかは案件ごとの判断です。**応じてはいけないという話ではありません。** 応じるときに、こちらの作業も一緒に減っているかどうか。そこだけ確かめれば、後から苦しくなることは減ります。

## まとめ

見積書で値引きを求められないための書き方をまとめます。

- **「一式」で書かない。**判断材料が無いと、総額への値引き要請になる
- 工程で**5〜8項目に割る。**相手が「要る／自分でやれる」を判断できる単位にする
- 値引きを言われたときに出す手を、**先に4つ用意しておく**（範囲を減らす／支払いを分ける／期間を延ばす／次の条件を付ける）
- **有効期限**を書く。書かないと半年前の金額で発注が来る
- **含まないもの**を明示する。揉めるのは金額ではなく範囲
- **修正の回数**を書く。書かないと終わりが見えない
- **前提条件**を書く。崩れたら金額が動くことを先に共有する

次に出す見積書で、まず1つだけやってみてください。**「一式」と書いていた行を、3つに割る。** それだけで、返ってくる言葉が変わります。
