採用したアルバイトが、数日で来なくなる。求人に費用をかけて、面接して、初日に立ってもらって、それで終わる。

**辞める理由の多くは、初日にあります。** 仕事が合わなかったのではなく、初日に「ここでやっていけるのか分からない」と感じさせてしまっている。

ここでは、教育をマニュアルにするときに何を書くか、初日をどう組み立てるかを書きます。分厚い冊子を作る話ではありません。

## アルバイト教育のマニュアルは、初日の3時間から作る

いきなり全業務のマニュアルを作ろうとすると、たいてい途中で止まります。項目が多すぎて終わらないからです。

**作る順番は、初日にやることから。** 具体的には、最初の3時間で教えることだけを書き出します。それ以外は後回しで構いません。

分厚いマニュアルを用意しても、初日に読ませる時間はありません。読んでもらえるのは、せいぜい1ページです。だったら、その1ページを先に作るほうが早い。

理由は単純で、**辞めるかどうかがそこで決まる**からです。3日目に教える業務のマニュアルが無くても、3日目まで残っていれば口頭で伝えられます。初日に来なくなったら、その機会自体がありません。

### 初日に教えることは、意外と少ない

書き出してみると、初日に必要なのはこのくらいです。

- 更衣室とロッカー、荷物の置き場所
- トイレ、休憩場所、水を飲む場所
- 名前を呼ぶ相手（今日その人に聞けばいい、という人を1人決める）
- タイムカードの押し方
- その日にやる作業、1つか2つ

**「その日にやる作業、1つか2つ」がポイントです。** 初日に5つも6つも教えると、何も覚えられません。1つを最後までできるようにするほうが、本人の手応えが残ります。

逆に、初日に教えなくていいことも決めます。クレーム対応、締め作業、レジの締め、発注。これらは「まだ教えていない」と本人に伝えておけば不安になりません。**教えていないことを明示するのも、教育のうち**です。

これを言わないと、本人は「知らないことを聞かれたらどうしよう」と身構えたまま3時間を過ごします。お客様に聞かれたときにどうするかまで決めておくと、さらに楽になります。「まだ入ったばかりで分からないので確認します、と言って◯◯さんを呼んで」。この一文があるだけで、立ち往生がなくなります。

## 初日を15分単位で区切る

マニュアルに書くのは、作業の手順だけではありません。**初日の時間の流れ**を書きます。

3時間を15分で区切ると、こうなります。

| 時間 | 内容 |
|---|---|
| 0:00〜0:15 | 出迎え、ロッカー案内、着替え |
| 0:15〜0:30 | 店内を一周。トイレ、休憩場所、水 |
| 0:30〜0:45 | 今日やることの説明。「今日はこれだけできれば十分」と伝える |
| 0:45〜1:15 | 一緒にやってみせる |
| 1:15〜1:45 | 横で見ながらやってもらう |
| 1:45〜2:00 | 休憩。1人にしない |
| 2:00〜2:45 | 1人でやってもらう。近くにいる |
| 2:45〜3:00 | 振り返り。次回の日程と、次に教えることを伝える |

この表は特定の店の実績ではなく、**組み立ての型**として示したものです。業種によって中身は変わりますが、区切りの考え方は同じように使えます。

型の中身は3段階です。**やってみせる → 横で見る → 1人でやる。** この順番を飛ばして、いきなり1人でやらせると、失敗の記憶だけが残ります。逆に見せるだけで終わると、できる気がしないまま帰ることになります。

そして最後の15分、**振り返りを必ず入れます。** ここで「次はいつ来るか」と「次に何を教えるか」を伝える。次の予定が決まっている人は、来なくなりにくい。

### 空白の時間を作らない

初日にいちばん効くのは、**手が空いて立ち尽くす時間をなくす**ことです。

「ちょっと待っててね」と言われたまま10分置かれると、その10分で「自分はここに必要ないのでは」と思わせます。忙しい時間に重ねてしまうと、これが起きやすくなります。

だから、**初日は暇な時間帯に入れる**ほうがいい。売上の山を手伝ってもらいたい気持ちは分かりますが、初日に限っては逆効果です。

### 休憩を1人にしない

上の表で「休憩。1人にしない」と書いたのは、ここで辞める判断が固まることが多いからです。

誰とも話さないまま15分座っていると、帰り道で「明日行くのやめようかな」になります。誰か1人が同じ時間に休憩に入る、それだけで変わります。

### 初日に一緒に立つ人を決めておく

「手が空いてる人が見てあげて」では、誰も見ません。**その日、その人を見る担当を1人決めます。**

決めるときの基準は、教えるのが上手いかどうかではなく、**その時間に余裕があるか**です。いちばんできる人が最も忙しいのはよくあることで、忙しい人に付けると空白の時間が生まれます。

担当になった人には、当日の朝に「今日◯◯さんの初日だから、3時間見てあげて」と伝えます。**当日いきなり頼むと、本人の段取りが崩れて雑になります。**

人の配置の考え方は[1WAY-3JOBの落とし穴](https://gouter.works/?p=9273)にも書いています。

## マニュアルは、写真と一文で足りる

文章で細かく書いたマニュアルは読まれません。**現場で見返せる形**にします。

**1作業1ページ。** 写真1枚と、手順を3〜5行。それ以上は入れない。

**主語を「あなた」にする。** 「〜が行われる」ではなく「あなたが〜する」。読んだ人が自分のこととして受け取れます。

**判断が必要なところだけ、条件を書く。** 「もし◯◯なら△△する」の形にする。それ以外は迷いようがないので、条件を書く必要がありません。

**置き場所を決める。** バックヤードの壁、共有のスマートフォンのフォルダ、どちらでもいい。**探さないと出てこないマニュアルは、無いのと同じ**です。

紙にするか画面にするかは、**その作業をどこでやるか**で決めます。厨房やレジ横のように手がふさがる場所は紙を貼る。事務作業なら画面でいい。両方に置くと、片方だけ更新されて食い違います。

更新したら、**古いほうを必ず剥がす**。新旧が並んでいると、どちらが正しいか誰も判断できなくなります。

### 作る人を1人にしない

マニュアルを店長が1人で作ると、終わりません。日々の業務のあとに書く時間が取れないからです。

**新しく入った人に書いてもらう**のが早い。教わった直後の人がいちばん「何が分からなかったか」を覚えています。教えた側は、できるようになりすぎていて、つまずく場所を忘れています。

1作業ぶん書いてもらって、教えた人が目を通す。この形なら、教育のたびにマニュアルが増えます。

**完成を目指さないこと。** 全業務を網羅した状態は、たぶん一生来ません。来月入る人の初日に使うぶんだけあればよく、足りない部分は次の人が書き足します。

書き方の統一も、最初から決めすぎないほうがいい。文体や見出しの形をそろえる作業に時間を取られて、肝心の中身が増えなくなります。**そろえるのは、ある程度たまってからで足ります。**

### 教える言葉をそろえる

同じ作業を、人によって違う言い方で教えると、新しく入った人は混乱します。「奥のやつ」「例のあれ」で通じるのは、長くいる人同士だけです。

**物と場所に名前を付けて、マニュアルに書きます。** 呼び方が2通りある物は、どちらかに決める。決めたら、教える側の全員がその言い方をする。

これは新人のためだけではありません。呼び方が統一されると、指示が短くなり、伝え間違いが減ります。**現場の言葉を整えることが、そのまま教育コストを下げます。**

ルールの決め方そのものは[複数人での編集方針とルールメイキング](https://gouter.works/?p=9281)と同じ考え方です。

## 辞める前に出るサインを見る

初日を乗り越えても、最初の2週間は離脱が起きます。**その前に出るサインは、だいたい同じ**です。

- シフトの希望を出すのが遅くなる
- 出勤して最初に誰にも話しかけなくなる
- 質問が減る（分からないことが減ったのではなく、聞きづらくなっている）

**質問が減ったら、こちらから聞きます。**「困ってることある？」だと「大丈夫です」で終わるので、「今日やった中で、やりにくかったのはどれ？」と作業を指して聞くほうが出てきます。

聞くタイミングは、**上がる直前ではなく、途中**にします。帰り際だと早く帰りたい気持ちが勝って、当たり障りのない返事になります。

出てきた「やりにくい」は、その場で直せるものだけ直します。全部を直そうとすると重くなるので、**次の出勤までに1つ**で十分です。1つでも直っていれば、言えば変わると分かります。

### 3回目の出勤までに、1回は雑談する

仕事の話しかしていない相手には、辞めると言いやすい。**仕事以外の会話が一度でもあると、言いにくくなります。**

大げさなことは要りません。通学先、来るときの交通手段、好きな食べ物。3回目までに1回、それで十分です。

とはいえ、無理に踏み込む必要はありません。プライベートを聞かれたくない人もいます。**天気と交通の話で十分**で、要は「仕事以外の言葉を交わした」という事実が残ればいい。

任せ方そのものの考え方は[外部パートナーの選び方と任せ方](https://gouter.works/?p=9278)にも通じます。

## まとめ

アルバイト教育のマニュアル化は、**初日の3時間から作る**のが順番です。

**初日に教えること** — 場所、聞く相手、タイムカード、そしてその日やる作業1〜2つ。教えないことも明示する。

**時間で区切る** — 15分単位で流れを決め、空白の時間を作らない。初日は暇な時間帯に入れる。休憩は1人にしない。

**マニュアルの形** — 1作業1ページ、写真1枚と3〜5行。主語は「あなた」。判断が要るところだけ条件を書く。探さずに出てくる場所に置く。

**書く人** — 教わった直後の人に書いてもらい、教えた人が確認する。店長が1人で書くと終わりません。

**辞める前のサイン** — シフト希望が遅くなる、話しかけなくなる、質問が減る。質問が減ったら、作業を指して聞く。

**雑談を1回** — 3回目の出勤までに、仕事以外の話を一度する。

まずは、**次に入る人の初日を15分単位で紙に書いてみてください。** 書けない時間帯が出てきたら、そこが空白になる場所です。埋められないなら、その日は初日に向いていない日です。
