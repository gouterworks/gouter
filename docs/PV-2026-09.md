# PVを見た（2026-09-09）

指標をPVに変えて最初の棚卸し。**期間は 2026/6/1〜9/8 の100日間。**

6月に手作業で20本ほど出したぶんが3か月経っているので、それが検索から
読まれ始めているかを見た。

## 結論

**読まれているのは、むかしの3本だけ。6月以降に出したコラムは、まだ検索から
人が来ていない。**

| | ページ数 | PV |

| **むかしの記事3本** | 3 | **349** |
| 6月のコラム（9134〜9290） | 28 | 142 |
| 9月からの毎日更新（9327〜9453） | 15 | 26 |

サイト全体で 1,264 PV。**上位3本だけで、6月以降のコラム全部の2倍。**

## 何が違うのか

読まれている3本は、どれも「探している人が、探している言葉で辿り着く」形になっている。

- **会計票テンプレート** — 持ち帰れるモノがある
- **ペン字の味方** — 特定のアプリの名前で探されている
- **1WAY-3JOB** — 特定の用語を調べた人が来る

いま出しているコラムは「◯◯のやり方」「◯◯は△△しない！」という**助言の形**。
同じ形の記事が世の中に無数にあり、区別がつかない。

**3か月経っても順位がつかないのは、「まだ早い」では説明がつかない。**
9月のぶんはまだ数日なので、これは判断できない。

## どうやって取ったか

**GA4は Windsor.ai 経由で読める。CSVの書き出しは要らない。**

```
connector : googleanalytics4
accounts  : ["271991344"]   （Goûter（グーテ） GA4）
```

使ったフィールド。**`get_fields` を先に呼ぶこと。推測した名前は通らない。**

| 欲しいもの | フィールドID |
|---|---|
| PV | `screen_page_views` |
| セッション | `sessions` |
| ページ | `page_path` `pagetitle` |
| 着地ページ | `landing_page` |
| 流入元 | `source` `medium` |
| 日付 | `date` |

ページ別のPVはこれで取れる。

```
get_data(connector="googleanalytics4", accounts=["271991344"],
         fields=["page_path", "screen_page_views", "sessions"],
         date_from="2026-06-01", date_to="2026-09-08")
```

記事IDの見分け方。**9327以降が、この案件で書いたもの**（`docs/articles/` の
フロントマターに `post_id` がある）。9134〜9302は6月に手作業で出したぶん。
`/9302-2` は固定ページなのでコラムに数えない。
